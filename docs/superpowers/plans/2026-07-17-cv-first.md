# CV на корень — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: `superpowers:executing-plans`. Шаги — чекбоксы (`- [ ]`).

**Goal:** `artfaal.ru` показывает CV, личная страница переезжает на `/life/`, «работа» — первая вкладка в nav.

**Architecture:** Физический переезд через `git mv` (тащит `og:type`, шрифты, title, description бесплатно).
Старый `/cv/` закрывается стабом-редиректом в репе. Хардкоды путей схлопываются в одну таблицу `PAGES`
в `test.js` **до** переезда — тогда сам переезд становится правкой одной строки.

**Tech Stack:** Static HTML + vanilla JS, без билда. GitHub Pages (не умеет 301) + Cloudflare (только DNS, proxy выключен).

**Спека:** `docs/superpowers/specs/2026-07-17-cv-first-design.md`

## Global Constraints

- **НЕ КОММИТИТЬ без явного ОК Макса.** «Погнали», «отлично», «хорошо» — это про работу, не про коммит.
  Явное разрешение — «коммить», «можно коммитить», «ок, коммит». Каждая задача заканчивается показом
  диффа и ожиданием, а не `git commit`.
- **Одна фича — один коммит.** 4 задачи = 4 будущих коммита, не смешивать.
- **Зоны других агентов — не трогать:** `generate-cv.js`, `assets/*.pdf` (PDF page-break);
  `.seg-cv` (`components.css:36-53`), `shared.js:137`, layout `.tb-right` (кнопка PDF).
  Перед каждой задачей — `git status`.
- **RU и EN синхронны** — любая правка `CONTENT.ru` дублируется в `CONTENT.en`. Перевод — литературный,
  через сабагента. Технические enum-поля (`status`, `icon`) не переводятся.
- **Проверка в браузере требует ручного `?v=`** — прогнать блок cache-busting из `.githooks/pre-commit`,
  иначе браузер отдаст кэш и поймаешь несуществующий баг.
- **Нет `!important`** кроме `prefers-reduced-motion`.
- `SKIP_PDF_GEN=1 node test.js` — тесты без перегенерации PDF (не будим зону PDF-агента).
